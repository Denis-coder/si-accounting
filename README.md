# Учёт СИ — GitHub Shared v16

Схема: GitHub Pages + `si-journal.json` + один Fine-grained GitHub token бригады.
Работникам GitHub-аккаунт не нужен.

## GitHub
Репозиторий: `Denis-coder/si-accounting`
Ветка: `main`
Файл общей базы: `si-journal.json`

## Первый запуск
1. Залить содержимое архива в корень репозитория.
2. Открыть GitHub Pages.
3. Нажать «Общая база» → «База» и указать `Denis-coder / si-accounting / main / si-journal.json`.
4. Создать Fine-grained token с доступом только к `si-accounting` и `Contents: Read and write`.
5. Вставить один токен бригады и сохранить.
6. «Первый запуск» → создать администратора.
7. Выбрать Excel.
8. «Опубликовать на сайт» — создаст `si-journal.json`.
9. Администратор открывает «Люди» и создаёт сотрудников.
10. Снова публикует.

## Работник
1. Открывает тот же сайт.
2. «Загрузить с сайта».
3. Вводит выданные ФИО/логин/пароль.
4. Один раз вводит тот же токен бригады в «База».

Изменения редакторов публикуются автоматически примерно через 2.5 секунды. Проверка новой версии общей базы выполняется примерно каждые 25 секунд.

## Важно
Один общий token означает, что каждый, кто знает token, технически может писать в репозиторий с правами этого token. Авторизация сотрудников в приложении нужна для журнала действий и разграничения ролей, но не заменяет серверную защиту GitHub token.
