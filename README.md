# Учёт СИ — PWA

Готовая веб-версия для Android. Открывается по HTTPS и может быть установлена на главный экран как приложение.

## Функции
- выбор XLSX;
- подсчёт СИ по рабочим строкам всех листов;
- просрочено / менее 3 месяцев / годно;
- поиск по заводскому номеру, названию, типу, месту, объекту и подразделению;
- QR: 14 полей слева направо через запятую;
- поиск по заводскому номеру;
- при отсутствии — подбор наиболее похожей записи и добавление рядом;
- просмотр и редактирование 14 полей;
- удаление строки;
- сохранение изменённого XLSX.

## Поверка
Контролируются только `Манометр` и `Термометр биметаллический`.
- дата: +1 год;
- `24ДЯУ`, `ДЯУ24`: до конца следующего года;
- `24ДЯУ2К`: до конца 2-го квартала следующего года;
- `2К24`, `3К24`: до конца указанного квартала следующего года.

## Запуск через GitHub Pages
1. Создайте аккаунт GitHub.
2. New repository, например `si-accounting`.
3. Загрузите `index.html`, `manifest.webmanifest`, `sw.js`.
4. Settings → Pages → Deploy from branch → `main` → `/root` → Save.
5. Откройте выданный `https://...github.io/si-accounting/` на Android.
6. Chrome → ⋮ → «Добавить на главный экран» / «Установить приложение».

## Важный нюанс
XLSX и QR-библиотеки сейчас подключены с CDN. Для первого запуска нужен интернет. После первого открытия оболочка PWA кэширует интерфейс, но браузер может потребовать сеть для библиотек CDN. Если нужна полностью автономная работа, скачайте `xlsx.full.min.js` и `html5-qrcode.min.js` и положите их в корень, заменив CDN-ссылки на локальные.

## Камера
Камера в браузере требует HTTPS (localhost — исключение). При первом сканировании разрешите доступ к камере.
