# Учёт СИ — PWA v14

Версия на базе рабочей v13 с общей базой через GitHub Contents API.

## Общая база

Файл `si-journal.json` хранится в том же GitHub-репозитории, что и сайт.

- Читать общую базу может любой посетитель публичного сайта.
- Для добавления, изменения и удаления нужен личный GitHub Fine-grained token.
- Token должен иметь `Contents: Read and write` только для репозитория приложения.
- Token сохраняется только в localStorage конкретного браузера и не попадает в репозиторий.
- Изменения после редактирования публикуются автоматически примерно через 2,5 секунды.
- Перед записью приложение сравнивает SHA файла. Если другой пользователь успел изменить базу, чужие изменения не перезаписываются.
- Версия общей базы проверяется примерно раз в минуту.
- В `history` хранится журнал последних изменений.

## Важно

Не используйте один и тот же token всеми сотрудниками. У каждого должен быть свой Fine-grained token. Если сотруднику больше не нужен доступ, его token можно отозвать в GitHub.

Не кладите token в `index.html`, GitHub Actions, README или любой другой файл репозитория.

Одновременные изменения защищены от тихого перезаписывания: при конфликте приложение предложит загрузить актуальную версию.

## Excel

Excel остаётся резервным способом хранения и обмена. После загрузки общей базы можно нажать «Сохранить Excel» и получить локальную копию.

## GitHub Pages

Загрузите содержимое архива в корень репозитория и включите GitHub Pages из ветки `main`.

Для работы камеры сайт должен открываться по HTTPS.
