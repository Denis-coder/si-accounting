КИП-конвертер — PWA без сборки и зависимостей.

Запуск локально (для проверки):
  любой статический сервер в корне папки, например:
  python -m http.server 8080  ->  http://localhost:8080

Публикация:
  1. Залейте ВСЕ файлы в корень репозитория GitHub
     (index.html, manifest.json, sw.js, папку icons).
  2. Settings -> Pages -> Source: Deploy from a branch,
     ветка main, папка / (root) -> Save.
  3. Через 1–2 минуты: https://логин.github.io/имя-репозитория/

Установка на телефон: открыть адрес в браузере,
Chrome/Android — «Установить приложение» (или «Добавить на главный экран»),
iPhone/Safari — «Поделиться» -> «На экран „Домой“».

Обновления: после изменения файлов поднимите константу CACHE в sw.js
(например, kip-v4 -> kip-v5), иначе браузер покажет старый кэш.
