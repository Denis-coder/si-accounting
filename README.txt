КИПиА — инженерный помощник (PWA)

Установка на GitHub Pages:
1. Создайте репозиторий.
2. Загрузите в корень репозитория: index.html, manifest.json, sw.js, папку icons.
3. GitHub -> Settings -> Pages -> Deploy from a branch -> main -> /(root) -> Save.
4. Откройте опубликованный HTTPS-адрес и добавьте на экран «Домой».

Обновление:
- При каждом изменении увеличивайте CACHE в sw.js (kip-assistant-v2 -> v3 и т.д.).
- Service worker кеширует приложение для офлайн-работы после первого открытия.
- Если поверх старой версии (kip-assistant-v1) заливаете эту — кеш обновится сам, потому что имя кеша другое.

Важно:
- Инструмент предназначен для инженерных оценок, а не заменяет паспорта, методики поверки, таблицы НСХ и нормативные документы.
- Расчёт термопар K/J — линейная аппроксимация, ориентировочный.
- SMD-маркировки неоднозначны между производителями, сверяйте с datasheet.
- Расчёт расхода Q=K*sqrt(dP) требует индивидуального коэффициента K из паспорта сужающего устройства.
- Расчёт сопротивления кабеля выполнен для 20 °C без учёта контактов и температурного коэффициента.
