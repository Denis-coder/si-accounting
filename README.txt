КИП КОНВЕРТЕР v5
================

Публикация на GitHub Pages:
1. Залейте в корень репозитория: index.html, manifest.json, sw.js, папку icons.
2. Settings -> Pages -> Deploy from a branch -> main -> /(root) -> Save.
3. Через 1-2 минуты приложение: https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/

После обновления файлов, если страница показывает старую версию:
поднимите версию кэша в sw.js (const CACHE = "kip-v5" -> "kip-v6") и перезалейте.

Разделы:
- Давление: конвертер единиц; уровень по давлению столба (P = ро*g*h).
- Темп.: °C/°F/K/°R; Pt100/Pt500/Pt1000 по МЭК 60751 (обе стороны пересчёта).
- Расход: объёмный, массовый; расход по перепаду давления (Q = K*корень(ДP)).
- Электр.: напряжение, ток, сопротивление, мощность, частота/об-мин.
- Цепи: R/C/L (последовательно/параллельно, любое число элементов);
  делитель напряжения (с учётом нагрузки); резистор светодиода (номинал E24, мощность);
  RC-цепь (тау и частота среза); падение напряжения на кабеле.
- Прочее: 4-20 мА (обе стороны, проверка NAMUR NE43); погрешности (абсолютная,
  относительная, приведённая); длина, масса, объём, плотность.
- Коды: цветовая маркировка резисторов (4 и 5 полос); SMD-резисторы (3 цифры,
  4 цифры, R-запятая, EIA-96); коды конденсаторов (104, 4R7, допуск J/K/M);
  коды катушек индуктивности.

У каждого расчёта серым текстом написано: что вводим и что получаем.
